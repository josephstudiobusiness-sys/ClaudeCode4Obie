ℹ How to use this tool

Load a file (WAV, MP3, or FRF: TRF/TRV/AvC/AvR/CSV/MAT) or record from the mic — each becomes a numbered row in the sidebar list.

🔎 Single shows one file, full width — the same checkbox Compare uses picks it: whichever checked file sits highest in the sidebar list. Check a lower file to bring it forward; uncheck it to fall back to the next checked one below.

🆚 Compare stacks the files whose checkbox is ticked in the sidebar, one row each, up to 6 at a time.

⛰ Difference shows the intensity difference between exactly two files — pick them with the small ① / ② buttons on each sidebar row. Mirror instead shows ① and ② side by side around a center line, without subtracting them.

🎙 Live watches the microphone continuously while you dial in FFT settings — nothing is saved.

🌀 Visualizer shows the same file Single would show as a circle — frequency around the circumference, time as the radius, colour as dB.

Only one microphone recording can run at a time.
