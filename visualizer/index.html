ℹ How to use this tool

Load a file (WAV, MP3, or FRF: TRF/TRV/AvC/AvR/CSV/MAT) — each becomes a numbered row in the sidebar list. Tick a row’s checkbox to make it the active file; ticking a different row switches the view.

▦ Planar — the classic flat spectrogram: time × frequency grid, colour = level.

🌀 Radial — the same data wrapped into a circle: frequency around the circumference (0 Hz at 12 o’clock, sweeping clockwise), time as the radius, colour = level.

⛰ 3D Surface — time × frequency grid with level as real, rotatable 3D height instead of colour alone.

The colour-scale picker (top right) applies to all three views — pick whichever reads best for the material.

⚙️ FFT Settings (window/hop/max-freq/smoothing) apply to whichever file is active.
